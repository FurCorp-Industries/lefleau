# Commandes Discord — noms anglais, modération directe

La limite de 100 commandes slash porte sur les commandes **racines**. Les sous-commandes comptent dans leurs groupes.

Les commandes de modération restent **directes** (`/ban`, `/kick`, `/warn`, etc.). Les autres groupes ont des noms anglais.

- Aucune fonction métier supprimée, seuls les chemins Discord sont réorganisés.

- Le site web reste disponible sans modification de ses routes HTTP.
