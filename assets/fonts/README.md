# Polices personnalisées (optionnel)

Dépose ici tes propres fichiers `.ttf` pour personnaliser le rendu de
l'affiche générée par `/profile` :

- `pirate_bold.ttf` → utilisée pour les textes en gras (WANTED, nom, prime)
- `pirate_regular.ttf` → utilisée pour les textes normaux (flotte/titre, pied de page)

Si ces fichiers sont absents, le bot utilise automatiquement une police
système par défaut (DejaVu Sans / Liberation Sans / Arial selon l'OS).

⚠️ Vérifie que la police que tu utilises est libre de droits ou que tu as
la licence adéquate pour l'utiliser dans ce contexte.
