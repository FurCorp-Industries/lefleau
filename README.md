# Le Fléau — One Piece Discord Bot

Bot Discord et panel web du projet Le Fléau.

## Version cible
v3.0.3 — Reaction Roles, gestion des tickets, giveaways, modération, économie et messages personnalisés.

## Import du code
Le code source complet doit encore être importé dans ce dépôt depuis l'archive `onepiece-discord-bot-github-ready.zip` préparée pour le projet.

## Sécurité
Ne jamais publier `.env`, tokens Discord, secrets OAuth, bases de données ou sauvegardes du serveur. Configurer les variables à partir de `.env.example`.

## Lancement
Consulter `README.md`, `requirements.txt` et `deploy/` après import du code.
